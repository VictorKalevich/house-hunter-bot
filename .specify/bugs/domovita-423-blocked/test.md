## Residual Risks

- Проверка через час (12:56) и дальнейший backoff на живом боте не дождались — их покрывает e2e (запрос ровно через
  час, раньше — ни одного) и прежний тест 403 (проверки через 1, 2, 4 ч).
- Частичный пропуск domovita остаётся: если плановая проверка попадёт в редкий 200, владелец получит «снова
  работает», а следующий 423 — «отказал боту». Теперь не чаще проверок по backoff (1, 2, 4, 8, 24 ч). Гистерезис — по
  решению владельца, см. Open Questions в assessment.md.
- Объявлений с domovita с адресов Cloudflare практически не будет; это ограничение сайта, обход запрещён FR-005.

## Recommendation

Закрыть: исправление проверено на живом боте и тестами. Если пары сообщений «отказал боту» / «снова работает» по
domovita будут мешать, это отдельное решение владельца о гистерезисе.
