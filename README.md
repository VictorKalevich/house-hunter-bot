# house-hunter-bot

Telegram-бот, который следит за объявлениями о продаже домов с участками на kufar.by, realt.by, domovita.by и
moyareklama.by и присылает сообщение, как только появляется новый дом под условия пользователя: цена, площадь
дома, площадь участка, расстояние от выбранного населённого пункта — по прямой, по дороге от центра или по дороге от
выезда. Поиски заводятся в мини-приложении Telegram, там же — список подходящих объявлений. Пользуются владелец и
приглашённые им люди.

Работает на бесплатном тарифе Cloudflare: Worker, база D1 и Cron Triggers (тик раз в минуту, суточная задача в
00:30 UTC). Сайты читаются бережно: только адреса, открытые в robots.txt, не чаще одного запроса к сайту в минуту,
честный User-Agent, без обхода защиты.

## Как пользоваться

- **Поиск**: `/start` → «Новый поиск» (или кнопка меню «Поиски» → «Новый поиск»). Населённый пункт выбирается из
  подсказок; если он выбран, расстояние обязательно — иначе поиск шёл бы по всей стране. Тип объекта — «Дом или
  коттедж», «Дача», «Часть дома или таунхаус» (по умолчанию все). Поиск без расстояния, цены и площадей можно
  сохранить, но бот сначала предупредит: это сотни сообщений в день.
- **Итог поиска**: после сохранения и из «Мои поиски» — условия, сколько объявлений подходит сейчас, «Показать
  объявления», пауза, «Изменить условия», «Копировать поиск», «Удалить поиск». Новые объявления приходят сообщением в
  чат: «Дача · 45 000 $ · дом 40 м² · участок 6 сот.».
- **Список объявлений**: метка «Новое» — объявление только что появилось на сайте; у остальных «обновлено …» (продавец
  мог поднять старое) и дата размещения, если сайт её даёт. Пока бот в первый раз читает сайты (до получаса после
  выката), пустой список говорит «Бот ещё собирает объявления».
- **Разные условия для разных сайтов**: сайтам условия не передаются — бот отбирает сам, поэтому это разные поиски.
  «Копировать поиск» → в копии оставить нужные сайты и поменять условия. Объявление под несколько поисков приходит
  одним сообщением. Охват: kufar.by и realt.by — вся страна, domovita.by — без дач, moyareklama.by — Гомель и
  окрестности, цена только в рублях.
- **Состояние сайтов**: внизу «Мои поиски» у всех пользователей — «Все сайты работают · проверены за последние N мин»
  или какой сайт не работает и с какого времени; сбой сайта поиска виден и на итоге, и над списком. Подробности
  сбоев — только владельцу: кнопка «Источники» и сообщения в чат.
- **Понравившиеся**: «♡ Нравится» под сообщением о доме и на карточке в списке поиска. Список у каждого свой: экран
  «♥ Понравившиеся» в мини-приложении или кнопка «Понравившиеся» в меню бота; свежие сверху, по 5 на странице, не
  больше 100 домов. Понравившийся дом не удаляется, даже если давно пропал с сайта, — пока не снимете лайк.
- **Не интересно**: кнопка под сообщением и на карточке убирает дом из ваших списков и сообщений, в том числе когда
  продавец его поднимет. Вернуть — «Скрытые» на экране «Понравившиеся» или «Скрыто · вернуть» под сообщением. Лайк и
  «Не интересно» у одного дома не бывают вместе.
- **Снято или нет**: страницу понравившегося дома на realt.by и moyareklama.by бот открывает раз в сутки, если дома
  не было в выдаче, — объявление снято → метка «Снято с сайта 24.11». kufar.by и domovita.by так не проверяются: если
  дома неделю нет в выдаче — «Не удалось проверить; в выдаче сайта последний раз …».
- **Цена**: у понравившегося дома цена сменилась на 1 % и больше — сообщение «Цена изменилась: было 52 000 $, стало
  48 000 $ (−4 000 $)». Сравнивается цена в валюте продавца, поэтому смена курса сообщений не даёт.

## Как устроено

| Где | Что |
|---|---|
| `src/index.js` | Вход Worker'а: HTTP (`src/http/router.js`) и cron (`src/jobs/tick.js`, `src/jobs/daily.js`) |
| `src/jobs/` | Шаги тика: отправка уведомлений → опрос лент → сохранение объявлений → отбор → маршруты; суточная задача: курс НБ РБ, чистка, отметки «новое», robots.txt |
| `src/sources/` | Адаптеры сайтов (`contracts/source-adapter.md`), нормализация, разбор robots.txt |
| `src/geo/` | Справочник пунктов, расстояния, границы, клиенты openrouteservice и OSRM |
| `src/telegram/`, `src/http/` | Webhook бота, сообщения владельцу, API и страница мини-приложения |
| `src/app/` | Мини-приложение: только компоненты дизайн-системы `design-system/` |
| `migrations/`, `seeds/` | Схема D1 и справочник населённых пунктов из OpenStreetMap |

Спецификация, план, модель данных и контракты — `specs/001-house-listing-alerts/`; улучшения поиска (тип объекта,
итог поиска, состояние сайтов) — `specs/002-search-ux-improvements/`; понравившиеся, «Не интересно» и изменение
цены — `specs/003-listing-likes/`.

## Команды

```powershell
npm install
npm test             # быстрые тесты: адаптеры на сохранённых страницах, фильтры, расстояния, тексты, безопасность
npm run test:e2e     # сквозные сценарии в Miniflare с подменой сайтов, Telegram и маршрутов (~1,5 мин)
npm run bench        # время разбора каждой сохранённой страницы против бюджета CPU
npm run dev          # локальный Worker: wrangler dev --test-scheduled
npx wrangler d1 migrations apply house-hunter --remote     # перед каждым выкатом: новые файлы migrations/*.sql
npm run deploy       # wrangler deploy
node scripts/setup-telegram.mjs [--dry-run]                # webhook, команды и кнопка меню бота
node scripts/build-settlements.mjs [--overpass-url URL]    # пересборка seeds/settlements.sql из OpenStreetMap
```

Установка, локальный запуск, выкат и проверка в Telegram — по шагам в
[quickstart.md](specs/001-house-listing-alerts/quickstart.md). Выкат начинается с миграций: Wrangler применяет только
ещё не применённые файлы (`0002_kinds.sql` добавляет тип объекта и типы в поиске, `0004_marks.sql` — отметки
«нравится» и «не интересно», сообщения о цене, цену в валюте продавца и проверку страниц), потом `npm run deploy`.

## Секреты

Секреты не хранятся в репозитории. Локально — файл `.dev.vars` (он в `.gitignore`; образец — `.dev.vars.example`), в
Cloudflare — `npx wrangler secret put <ИМЯ>`:

| Имя | Что |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `WEBHOOK_SECRET` | Случайная строка: Telegram присылает её в заголовке `X-Telegram-Bot-Api-Secret-Token` |
| `OWNER_TELEGRAM_ID` | Telegram ID владельца |
| `ORS_API_KEY` | Ключ openrouteservice (account.heigit.org) |

Открытые переменные `BOT_USERNAME` и `PUBLIC_URL` — в `wrangler.jsonc`.

## Как вносить изменения

Любое изменение поведения — через Spec Kit: `/speckit-specify` → `/speckit-plan` → `/speckit-tasks` →
`/speckit-implement`; каждый план сверяется с конституцией `.specify/memory/constitution.md`. Интерфейс — только из
дизайн-системы `design-system/`. Перед слиянием — зелёные `npm test`, `npm run test:e2e` и `npm run bench`.
Подробности — `CLAUDE.md`.
