# Дизайн-система House Hunter

Единственный источник внешнего вида интерфейса бота: мини-приложения Telegram (настройка поисков, список
объявлений) и любых других страниц проекта. Версия 0.1.0 — основа: токены и базовые компоненты.

| Файл | Что внутри |
|---|---|
| `tokens.css` | Токены `--ds-*`: цвета, типографика, отступы, радиусы, размеры, тени, движение, слои. Единственное место с «сырыми» значениями |
| `components.css` | Компоненты `.ds-*` — только через токены |
| `preview.html` | Витрина: все компоненты в светлой и тёмной теме Telegram. Открывается прямо из папки в браузере |

## Принципы

1. **Тема Telegram — основа.** Цвета интерфейса берутся из `--tg-theme-*` (bg, section_bg, text, hint, link,
   button, destructive, section_header, section_separator), поэтому светлая и тёмная темы работают сами. Запасные
   значения — для обычного браузера.
2. **Бренд «дом и участок» — дозированно.** Зелёный градиент `--ds-gradient-brand` — только шапка (`ds-hero`) и
   метка «Новое» (`ds-chip--brand`). Действия — цветом кнопок Telegram (`--ds-color-accent`).
3. **Фиксированные цвета читаются в обеих темах.** Бренд, статусы и всплывающее сообщение не зависят от темы:
   это сплошная заливка с белым текстом, контраст ≥ 4.5 : 1 (проверяет тест).
4. **Шкала отступов 4 px.** Только `--ds-space-*`; других отступов нет.
5. **Крупные цели для пальца.** Высота интерактивных элементов ≥ 34 px (`--ds-size-control-sm`), основные
   кнопки и поля — 44 px (`--ds-size-control`).
6. **Нет данных — так и пишем.** Значение, которого нет в объявлении, показывается словами «не указано»
   (`ds-fact__value--unknown`), а не прочерком и не пустым местом.

## Компоненты

| Компонент | Классы | Для чего |
|---|---|---|
| Основа | `ds-root`, `ds-theme` | Корень страницы (шрифт, фон, цвет); `ds-theme` — пересчитать токены внутри блока с другой темой |
| Раскладка | `ds-page`, `ds-stack` (`--tight`, `--loose`), `ds-row` (`--between`, `--wrap`), `ds-grow`, `ds-divided` | Страница, вертикальные и горизонтальные группы |
| Текст | `ds-title`, `ds-text-muted`, `ds-text-sm`, `ds-text-strong`, `ds-num`, `ds-hint` | Заголовок, второстепенный текст, числа (`ds-num` — цифры одной ширины, без переноса) |
| Шапка | `ds-hero` (`__title`, `__text`) | Шапка главного экрана в цветах бренда |
| Секция | `ds-section-title`, `ds-card` (`--flush`) | Заголовок группы и карточка на фоне секции |
| Кнопки | `ds-btn` (`--block`, `--secondary`, `--danger`, `--sm`), `ds-icon-btn` | Действия; `disabled` — недоступна |
| Поля | `ds-field` (`__label`, `__hint`), `ds-input` (`--error`), `ds-affix` (`__unit`, `--error`), `ds-range` (`__sep`) | Подпись + поле + подсказка; поле с единицей («км», «м²», «сот.», «$»); диапазон «от — до» |
| Подсказки при вводе | `ds-suggest` (`__item`, `__item--active`, `__name`, `__meta`) | Выбор населённого пункта: название и район/область, чтобы различать одноимённые |
| Один из вариантов | `ds-options`, `ds-option` (`__input`, `__body`, `__title`, `__hint`) | Радиокнопки с пояснением (способ подсчёта расстояния) |
| Переключатель | `ds-switch` (`__input`, `__track`) | Вкл/выкл (сайты поиска, пауза) |
| Список | `ds-list`, `ds-list-item` (`__body`, `__title`, `__meta`, `--link`) | Строки с разделителями; `--link` — строка-кнопка со стрелкой |
| Метки | `ds-chips`, `ds-chip` (`--brand`, `--success`, `--warning`) | Источник, «Новое», «Активен», «Пауза» |
| Объявление | `ds-listing` (`__photo`, `__photo--empty`, `__body`, `__top`, `__price`, `__price-alt`, `__facts`, `__place`, `__meta`), `ds-fact` (`__label`, `__value`, `__value--unknown`) | Карточка: фото, цена ($ и BYN), дом, участок, расстояние, место, сайт и время |
| Страницы | `ds-pager` (`__info`) | «Назад», «1–5 из 37», «Дальше» |
| Пустое состояние | `ds-empty` (`__icon`, `__title`, `__text`) | Ничего не нашлось + что сделать |
| Загрузка | `ds-spinner` | Индикатор загрузки |
| Всплывающее сообщение | `ds-toast` | Короткое подтверждение («Поиск сохранён») |

## Правила (проверяет `tests/design-system.test.mjs`)

- В `components.css` нет «сырых» цветов (`#…`, `rgb()`, `hsl()`) и значений в `px` — только `var(--ds-*)`.
- Базовые стили элементов (`button`, `input`, …) задаются только через `:where()` — у них нулевая специфичность,
  поэтому они никогда не перебивают цвета и размеры компонентов.
- Каждый `var(--ds-*)` в компонентах и витрине определён в `tokens.css`.
- Каждый компонент показан в `preview.html`, каждый класс `ds-*` витрины описан в `components.css`.
- Системные элементы — в схеме темы: `color-scheme: var(--ds-color-scheme)` на корне и в `.ds-theme`, пункты
  `<option>` — цвета `surface`/`text`.
- Белый текст на фиксированных цветах (бренд, статусы, всплывающее сообщение) — контраст ≥ 4.5 : 1.
- В мини-приложении (`src/app/`) нет своего CSS (кроме места для дизайн-системы `<style>/*@design-system*/</style>`),
  атрибутов `style`, «сырых» цветов и px, классов вне `ds-*`; каждый используемый класс описан в `components.css`.
  Пока мини-приложения нет, эти две проверки пропускаются.
- `preview.html` сам по себе — витрина: в его `<style>` только раскладка колонок и имитация темы Telegram
  (`--tg-theme-*`), компоненты там не стилизуются.

## Как добавить новый элемент

1. Нужен новый цвет или размер → добавить токен в `tokens.css` (с понятным именем; фиксированный цвет под
   белым текстом — добавить пару в тест контраста).
2. Описать компонент в `components.css` (БЭМ: `.ds-блок__элемент--модификатор`), только через токены.
3. Показать его в `preview.html` (в обеих темах он появится сам).
4. Добавить строку в таблицу компонентов выше.
5. Использовать в интерфейсе. Запустить `npm test`.

## Как подключается

Сервер встраивает `tokens.css` и `components.css` в `<style>` страницы мини-приложения вместо места
`/*@design-system*/`, поэтому сборщик не нужен (как именно — решит план фичи). Сообщения бота в чате Telegram —
обычный текст без CSS, дизайн-система к ним не относится.
