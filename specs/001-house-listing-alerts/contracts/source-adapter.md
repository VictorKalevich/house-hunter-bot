# Контракт: адаптер источника объявлений

Каждый сайт — модуль `src/sources/<id>.js` с одинаковым интерфейсом. Общий код (`src/jobs/poll-feeds.js`) только
скачивает страницу, вызывает адаптер, сохраняет результат и ведёт состояние источника; про вёрстку сайта он
ничего не знает. Как читать каждый сайт — [research.md](../research.md#r1-источники-объявлений).

## Интерфейс

```js
// src/sources/<id>.js
export default {
  id: 'realt',                         // kufar | realt | domovita | moyareklama
  title: 'realt.by',
  origin: 'https://realt.by',
  allowHosts: ['realt.by'],            // ссылки объявлений — только на эти хосты (сверка строгая, без поддоменов)
  idKind: 'created_at',                // 'numeric' — номера растут (новое = выше суточной отметки)
                                       // 'created_at' — сайт даёт дату создания
  paging: 'cursor',                    // необязательно: следующая страница только по nextCursor (kufar)
  resetStateOn404: true,               // необязательно: 404 страницы ленты → состояние сброшено (domovita: buildId)
  feeds: [                             // ленты: регионы и разделы; каждая — один круг опроса
    { key: 'gomel-region:cottages', path: '/gomel-region/sale/cottages/', maxPages: 2, cost: 2 },
    // …
  ],
  intervalMin: 20,                     // круг ленты — раз в intervalMin + случайно 0–5 мин (15–30, FR-003)

  /**
   * Запрос страницы ленты. Только адреса и параметры, открытые в robots.txt. Нет нужного курсора — исключение
   * (лента начинает круг заново). purpose: 'state' — вместо страницы нужен запрос состояния (domovita без buildId);
   * readLimitBytes — читать только начало ответа.
   */
  pageRequest(feed, page, cursor, state) { return { url: '…', accept: 'text/html', purpose: 'page', readLimitBytes: 0 }; },

  /** Необязательно: разбор ответа на запрос purpose: 'state' → новое состояние или null. */
  parseState(body) { return { buildId: '…' }; },

  /** Разбор ответа. Чистая функция: без сети, без D1, без текущего времени — тесты на сохранённых страницах. */
  parsePage(body, { feed, page }) {
    return {
      items: [/* RawListing */],
      nextCursor: null,                // курсор следующей страницы (kufar)
      total: 10204,                    // счётчик выдачи, если сайт его даёт
      looksValid: true,                // есть признаки выдачи (контейнер/ключи JSON/ожидаемый раздел)
      wrongSection: false,             // сайт отдал другой раздел (квартиры вместо домов) → сбой parse
      state: null,                     // что запомнить для следующих запросов (domovita: buildId)
    };
  },

  /** Необязательно: карточка объявления, если в выдаче нет нужного поля (moyareklama — координаты). */
  detailRequest(externalId) { return { url: '…', accept: 'text/html' }; },
  parseDetail(body) { return { coords: { lat, lon } }; },
};
```

`RawListing` — что адаптер нашёл на странице, без пересчётов:

| Поле | Тип | Пример |
|---|---|---|
| `externalId` | string, обязательно | `"1048576"` |
| `url` | string, обязательно, `https://` на домен источника | `"https://re.kufar.by/vi/1048576"` |
| `kind` | `house` \| `dacha` \| `cottage` \| `part` | тип объекта; прочее (квартиры, участки без дома, «Прочее») адаптер отбрасывает |
| `paid` | boolean | платное/закреплённое (идёт выше свежих; не участвует в правиле «круг закончен») |
| `price` | `{ amount, currency: 'USD' \| 'BYN' \| 'EUR' }` \| null | `{ amount: 75000, currency: 'USD' }`; «договорная» и 0 → null |
| `priceUsd` | number \| null | цена в $, если сайт её сам показывает (kufar, realt, domovita) |
| `priceByn` | number \| null | цена в BYN, если сайт её показывает |
| `houseArea` | `{ value, unit: 'm2' }` \| null | |
| `plotArea` | `{ value, unit: 'sotki' \| 'ha' \| 'm2' }` \| null | |
| `coords` | `{ lat, lon }` \| null | только если сайт даёт координаты; порядок у сайтов разный — адаптер приводит к `lat, lon` |
| `place` | `{ text, settlement, district, region }` | `text` — как на сайте; остальное — если удалось выделить |
| `publishedAt` | ISO-строка \| null | дата публикации или поднятия |
| `siteCreatedAt` | ISO-строка \| null | дата создания (`idKind: 'created_at'`) |
| `photoUrl` | string \| null | одна ссылка |

Имена, телефоны и e-mail продавцов адаптер не читает в `RawListing`, они не хранятся и не попадают в логи
(принцип I, раздел «Безопасность и данные»).

Нормализация (`src/sources/normalize.js`, общая): цена → `price_usd` (если сайт не дал $ — пересчёт BYN по курсу
НБ РБ), участок → сотки, место без координат → справочник пунктов (`name + district + region`), `geo_key`,
`is_new` по `idKind`.

## Ошибки и состояние источника

`poll-feeds` классифицирует результат запроса:

| Что произошло | `error_kind` | Состояние |
|---|---|---|
| 200, `items.length > 0` | — | `ok` |
| 200, `items.length = 0`, `looksValid = true`, `total = 0` | — | `ok` (на реальной ленте так не бывает — после 3 раз подряд считается `empty`) |
| 200, `items.length = 0`, а `looksValid = false` или `total > 0` | `parse` | `failing` — вёрстка поменялась |
| 200, но у > 50 % объявлений нет ни цены, ни площадей, ни места | `parse` | `failing` — поля перестали распознаваться |
| 200, но раздел не тот (например, domovita отдала квартиры) | `parse` | `failing` |
| 404 у маршрута с версией сборки (domovita `_next/data`) | — | не сбой: в следующем тике прочитать HTML и обновить `buildId` |
| 403, 429, капча, страница проверки браузера (`cf-mitigated`, «Just a moment…») | `blocked` | `blocked`, без повторов в этом круге |
| 5xx, тайм-аут 15 с, сетевая ошибка | `http` | `failing` |

Правила (принцип I, FR-003, FR-005):

- К сайту — не больше одного запроса в тик (пауза ≥ 1 мин): страницы лент и карточки идут по очереди.
- Только адреса из `feeds`, `?page=N` и карточки — то, что открыто в robots.txt. Раз в сутки суточная задача
  (`robotsDailyStep` в `src/jobs/poll-feeds.js`) скачивает robots.txt каждого сайта и сверяет с ним адреса лент,
  страниц и карточек; закрытый адрес → источник `disallowed` и сообщение владельцу. Если сверка не прошла (сайт был
  занят), её делает тик, когда прошлой больше 26 ч.
- Следующая страница ленты (до `maxPages`) читается, только если последнего неплатного объявления страницы не было
  в прошлом круге этой ленты (`feeds.prev_ids`); иначе круг закончен.
- Заголовки честные: `User-Agent: house-hunter-bot/<версия> (+https://t.me/<бот>)`, `Accept`,
  `Accept-Language: ru`. Адреса, заголовки, cookie и прокси для обхода отказов не меняются.
- `cost` ленты — оценка CPU на разбор её страницы (единица ≈ 1 мс в `npm run bench`); тик берёт ленты, пока сумма
  ≤ 6.

## Тесты (принцип V)

- `tests/sources/<id>.test.mjs` на сохранённых страницах `tests/fixtures/<id>/*`: число объявлений, все
  обязательные поля, доля распознанных цены/площадей/места ≥ 95 % там, где сайт их показывает (SC-004), платные
  помечены, чужие типы объектов отброшены, контактов продавца в результате нет.
- Страница защиты от ботов, пустая и сломанная страница, чужой раздел → верная классификация ошибки.
- Сайт поменял вёрстку → сначала новая сохранённая страница и падающий тест, потом правка адаптера.
- `npm run bench`: время разбора каждой сохранённой страницы в Node (медиана 20 прогонов); медиана дороже своего
  `cost` мс — ошибка, дороже половины `cost` — предупреждение «мало запаса».
