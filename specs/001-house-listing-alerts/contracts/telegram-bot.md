# Контракт: Telegram-бот

Что бот принимает от Telegram и что отправляет. Тексты — по-русски, без команд с параметрами для пользователя
(FR-011, принцип VI). Весь текст с сайтов и от пользователей экранируется для `parse_mode: HTML` (`&`, `<`, `>`).

## Webhook

| | |
|---|---|
| Адрес | `POST /telegram/webhook` |
| Проверка | Заголовок `X-Telegram-Bot-Api-Secret-Token` равен секрету `WEBHOOK_SECRET`, иначе `401` без обработки |
| Подписка | `setWebhook(url, secret_token, allowed_updates: ["message", "callback_query"])` — скрипт `scripts/setup-telegram.mjs` |
| Ответ | Всегда `200` после обработки (ошибка — в лог). Повторная доставка того же обновления безопасна: вход по приглашению и действия владельца идемпотентны |

## Доступ (FR-018, FR-019, US6)

Перед любой обработкой:

| Кто пишет | Что делает бот |
|---|---|
| ID = `OWNER_TELEGRAM_ID` | Создаёт/обновляет запись владельца, обрабатывает как обычно |
| `users.access = active` | Обрабатывает; если был `blocked_at` — очищает |
| `users.access = revoked` | «Доступ к боту закрыт владельцем.» Больше ничего |
| Нет записи, `/start inv_<token>`, приглашение свободно | Создаёт `users` (`member`, `active`, `invited_by`), тратит приглашение, отвечает приветствием |
| Нет записи, приглашение использовано или неизвестно | «Это приглашение уже использовано или недействительно. Попросите у владельца новую ссылку.» + отметка в `access_denials` |
| Нет записи, без приглашения | «Этот бот работает только по приглашению. Попросите ссылку у владельца.» + отметка в `access_denials` |

## Команды и кнопки

Меню команд (`setMyCommands`): только `/start` — «Главное меню». Кнопка меню чата (`setChatMenuButton`, тип
`web_app`) — «Поиски» → `/app`.

**Главное меню** (ответ на `/start` и любой текст):

> Я присылаю новые объявления о домах с участками с kufar.by, realt.by, domovita.by и moyareklama.by.
> Создайте поиск — и я напишу, как только появится подходящий дом.

| Кнопка | Тип | Действие |
|---|---|---|
| Новый поиск | `web_app` → `/app#/search/new` | Форма поиска (US1) |
| Мои поиски | `web_app` → `/app#/` | Список поисков (US2, US4) |
| Пригласить | `callback_data: inv:new` | Только владелец |
| Пользователи | `callback_data: users:0` | Только владелец |
| Источники | `callback_data: src` | Только владелец: состояние сайтов |

**Действия владельца** (`callback_data` ≤ 64 байт; чужие нажатия — `answerCallbackQuery` «Нет доступа»):

| `callback_data` | Ответ |
|---|---|
| `inv:new` | «Ссылка-приглашение для одного человека: https://t.me/<бот>?start=inv_<token>. Перешлите её тому, кого хотите пустить.» |
| `users:<offset>` | Список по 10: «Имя (@username) — с 22.11.2026», у каждого кнопка «Закрыть доступ» → `rv:<telegram_id>`; «Дальше» → `users:<offset+10>` |
| `rv:<id>` | Подтверждение: «Закрыть доступ <Имя>? Его поиски остановятся.» — «Да, закрыть» → `rv!:<id>`, «Отмена» |
| `rv!:<id>` | `access = revoked`, ожидающие уведомления → `undeliverable`; «Доступ закрыт.» Владельцу закрыть доступ себе нельзя |
| `src` | По строке на источник: «kufar.by — работает, проверен 14:05» / «realt.by — сбой с 13:20: 503» |
| `probe:<source>` | Внеочередная проверка источника в ближайший тик; «Проверю в течение минуты.» |

## Уведомление о новом объявлении (FR-012…FR-014)

`sendMessage`, `parse_mode: HTML`:

```text
<b>75 000 $</b> · дом 100 м² · участок 15 сот.
25 км по прямой от Минска
д. Боровляны, Минский р-н
kufar.by · Поиски: «Минск · до 30 км по прямой», «Боровляны · до 10 км»
```

- Цена: `$`, если есть, иначе `BYN`; нет цены или «договорная» → «цена не указана». Площади без данных — «дом: не
  указано», «участок: не указано».
- Расстояние: «N км по прямой / по дороге от центра / по дороге от выезда из <пункт>»; «≈», если место по центру
  деревни; «по прямой (маршрут не построен)» при запасном расчёте. Для поиска без ограничения расстояния строки нет.
  Если объявление подошло под несколько поисков с расстоянием — расстояние для первого из них.
- Кнопка `url` «Открыть объявление» → ссылка на сайт.
- `link_preview_options`: `{ url: photo_url, prefer_large_media: true, show_above_text: true }`, если есть фото;
  иначе превью выключено.

Обработка ответа Telegram (состояния — [data-model.md](../data-model.md#notifications--уведомление)):

| Ответ | Действие |
|---|---|
| `ok: true` | `sent` |
| `429`, `parameters.retry_after` | Отправку в этом тике прекратить; `next_attempt_at = сейчас + retry_after` |
| `403` (бот заблокирован, пользователь удалён) | `undeliverable`, `users.blocked_at = сейчас`; не сбой |
| `400` | `failed`, ошибка в лог |
| `5xx`, сеть | `pending`, следующая попытка через 1, 5, 15, 60 мин (FR-015) |

Темп: не больше 20 сообщений за тик и не больше одного в секунду в один чат.

## Сообщения владельцу о сбоях (FR-020, US5)

Одно сообщение на сбой источника и одно — при восстановлении:

| Случай | Текст | Кнопка |
|---|---|---|
| 3 сбоя подряд (`http`) | «kufar.by не отвечает с 22.11 14:05: 503 Service Unavailable (3 проверки подряд). Остальные сайты работают.» | «Проверить сейчас» → `probe:kufar` |
| Разбор (`parse`, `empty`) | «realt.by перестал распознаваться с 22.11 14:05: на странице нет объявлений в ожидаемом виде. Нужна правка разбора.» | то же |
| Защита (`blocked`) | «domovita.by отказал боту с 22.11 14:05 (403, страница защиты от ботов). Обходить защиту бот не будет; следующая проверка через 1 ч, дальше реже.» | то же |
| Восстановление | «kufar.by снова работает. Сбой длился 2 ч 10 мин.» | — |
