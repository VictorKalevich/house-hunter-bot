# Контракт: изменения API и экранов мини-приложения (фича 002)

Базовый контракт — [miniapp-api.md фичи 001](../../001-house-listing-alerts/contracts/miniapp-api.md): авторизация,
ошибки, `Settlement`, `Search` и методы остаются. Здесь — только то, что добавляется или меняется. Модель —
[data-model.md](../data-model.md).

## Объекты

```jsonc
// Criteria — добавлено поле kinds; остальное как в 001
{
  "settlementId": 1234,            // если задан — maxKm обязателен (новое правило, FR-008)
  "distanceMode": "road_exit",
  "maxKm": 30,
  "priceUsd":  { "min": null, "max": 80000 },
  "houseM2":   { "min": 80,   "max": null },
  "plotSotki": { "min": 10,   "max": null },
  "kinds": ["house", "dacha", "part"],                        // новое: непустое; во входе необязательно (нет → все три)
  "sources": ["kufar", "realt", "domovita", "moyareklama"]
}

// ListingCard — добавлены kind, isNew, createdAt
{
  "source": "realt", "url": "https://realt.by/…", "photoUrl": null,
  "kind": "dacha",                       // "house" | "cottage" | "dacha" | "part" | null (неизвестен)
  "isNew": false,                        // новое на сайте (то же правило, что для уведомлений)
  "priceUsd": 45000, "priceByn": null, "houseM2": 40, "plotSotki": 6,
  "distance": { "km": 25.4, "mode": "straight", "approx": false, "fallback": false, "pending": false },
  "place": "д. Боровляны, Минский р-н",
  "publishedAt": "2026-11-22T09:41:00Z",  // как в 001: размещение или поднятие по данным сайта (иначе — когда бот увидел)
  "createdAt": "2026-10-03T08:00:00Z"     // новое: дата размещения, если сайт её даёт (realt, domovita), иначе null
}

// SourceStatus — новое
{ "id": "realt", "title": "realt.by", "state": "down", "since": "2026-11-22T11:05:00Z", "checkedAt": "2026-11-22T10:40:00Z" }
// state: "ok" | "collecting" | "down"; since — начало подтверждённого сбоя (только у down), иначе null;
// checkedAt — последняя успешная проверка или null. Технических подробностей сбоя нет.
```

## Методы

| Метод и путь | Изменение | Требования |
|---|---|---|
| `POST /api/searches`, `PUT /api/searches/{id}` | Принимают `kinds`; `422` с `fields.kinds`, если список пуст или в нём неизвестное значение; `422` с `fields.maxKm` «Укажите расстояние или очистите населённый пункт», если задан `settlementId`, а `maxKm` — нет. Название: `road_center` → «по дороге от центра» | FR-003, FR-008, FR-010 |
| `GET /api/searches`, `GET /api/searches/{id}` | `criteria.kinds` в ответе | FR-015 |
| `GET /api/searches/{id}/listings?page=n` | Отбор учитывает `kinds` (объявление с `kind = null` проходит). В ответе, кроме `items`, `page`, `pageSize`, `total`: `totalApprox` — `true`, если `total` — нижняя граница (прочитан предел строк); `distancesPending` — `true`, если у части подходящих дорожное расстояние ещё считается | FR-004, FR-007, FR-011 |
| `GET /api/sources` | Новый: `{ "items": [SourceStatus] }` — все четыре сайта в порядке kufar, realt, domovita, moyareklama; для любого пользователя с доступом (иначе 401/403, как остальные методы) | FR-017, FR-018 |

Правила проверки `Criteria` (дополняют 001):

- `kinds` — непустое подмножество `house`, `dacha`, `part`; ответ хранит их в этом порядке.
- `settlementId` задан → `maxKm` обязателен (раньше было только обратное: `maxKm` → `settlementId`).

## Экраны

| Экран | Адрес (hash) | Что меняется | Компоненты |
|---|---|---|---|
| Мои поиски | `#/` | Описание поиска перечисляет типы и сайты, если выбраны не все; внизу — строка о сайтах (`GET /api/sources`) | как в 001 + `ds-hint`, `ds-card` |
| Итог поиска | `#/search/{id}` | **Новое назначение адреса** (в 001 — форма). Заголовок и метка «Активен»/«Пауза»; условия строками; «Сейчас подходит N объявлений» («не меньше N» при `totalApprox`) и «Показать объявления»; при `distancesPending` — «число может уточниться»; «Новые объявления пришлю сообщением в этот чат» или «Поиск на паузе — уведомления не приходят»; сайты поиска в состоянии `down`; переключатель паузы; «Изменить условия», «Копировать поиск», «Удалить поиск» | `ds-title`, `ds-chip--success`/`--warning`, `ds-list`/`ds-list-item`, `ds-card`, `ds-btn--block`/`--secondary`/`--danger`, `ds-switch`, `ds-hint`, `ds-toast` |
| Новый поиск | `#/search/new` | Блок «Тип» (три переключателя); у сайтов — подписи охвата; подсказка расстояния зависит от того, выбран ли пункт; проверка «пункт без расстояния»; предупреждение «без условий» (`showPopup`, запасной `confirm`) | как в 001 + `ds-list-item__body`/`__title`/`__meta` |
| Изменить поиск | `#/search/{id}/edit` | **Новый адрес** (форма из 001), те же изменения формы | то же |
| Копия поиска | `#/search/new?copy={id}` | Новая: форма нового поиска с условиями поиска `{id}`, заголовок «Копия: <название>» | то же |
| Объявления поиска | `#/search/{id}/listings?page=n` | Метки карточки: тип, «Новое» (`ds-chip--brand`), сайт — сайт только здесь, в `__meta` его больше нет; время: «размещено …» у нового, «обновлено …» (+ «· размещено <дата>») у остальных; счётчик «из N+» при `totalApprox`; пустой список при `collecting` у сайтов поиска — «Бот ещё собирает объявления»; сайты поиска в `down` — строкой над списком | как в 001 + `ds-chip--brand` |

Переходы: после «Сохранить» (новый, копия, изменение) — `#/search/{id}` и «Поиск сохранён». «Назад» Telegram: итог →
«Мои поиски»; изменение и копия → итог исходного поиска; новый поиск → «Мои поиски»; объявления → итог. Кнопки
меню бота (`/app#/search/new`, `/app#/`) не меняются.
