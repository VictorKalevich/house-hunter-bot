## 1. Быстрые тесты

```powershell
npm test
```

Ожидание: всё зелёное, в том числе:

| Что | Ожидание |
|---|---|
| Адаптеры на сохранённых страницах | У каждого объявления тип из четырёх; после нормализации он есть в строке объявления |
| Условия поиска | Объявление с `kind = null` проходит любой выбор типов; «Дом или коттедж» пропускает дом и коттедж, но не дачу |
| Проверка условий | Пункт без расстояния → ошибка у расстояния; пустой `kinds` → ошибка типов; без `kinds` → все три; название «… по дороге от центра» |
| Текст уведомления | «Дача · <b>45 000 $</b> · дом 40 м² · участок 6 сот.»; без типа — как в 001 |
| Карточка | `kind`, `isNew`, `createdAt` |
| Состояние сайтов | `blocked`/`disallowed` → `down`; `failing` с 1–2 сбоями → не `down`, с 3 → `down`; лента без `last_ok_at` → `collecting` |
| Дизайн-система | Мини-приложение — только классы `ds-*` из `components.css` |

## 3. Мини-приложение вручную

Витрина `design-system/preview.html` не меняется — новых компонентов нет. Экраны проверяются в Telegram после выката
(шаг 4); локально — `npx wrangler dev` и `/app` в браузере (без Telegram запросы к API отвечают 401 — видна только
вёрстка экрана ошибки).

## 4. Выкат

Вместе с 001 (если 002 готова к выкату 001, quickstart 001 §7) или отдельно — сначала миграция, потом код:

```powershell
npx wrangler d1 migrations apply house-hunter --remote   # применит 0002_kinds.sql (и 0001, если ещё нет)
npx wrangler deploy
```

Код 001 с уже применённой 0002 работает, поэтому миграцию можно применить и заранее.

## 5. Проверка в Telegram после выката

1. **Новый поиск** (US3): выбрать «Боровляны», расстояние не заполнять → «Сохранить» — ошибка у расстояния. Стереть
   пункт, очистить всё → «Сохранить» — окно «Поиск без условий»; «Отмена» — назад в форму.
2. **Итог** (US2): поиск «Минск, 30 км по прямой, до 80 000 $» → «Сохранить» → итог: условия, «Сейчас подходит N»,
   «Новые объявления пришлю сообщением в этот чат». «Показать объявления» → в списке столько же. В первые полчаса
   после выката — «Бот ещё собирает объявления».
3. **Типы** (US1): в поиске оставить «Дом или коттедж» → в списке нет дач; уведомления начинаются со слова «Дом» или
   «Коттедж».
4. **Список** (US4): у части карточек метка «Новое»; у остальных «обновлено …», у realt и domovita ещё «размещено …»;
   сайт в карточке — один раз.
5. **Сайты** (US5): у сайтов в форме подписи охвата; «Копировать поиск» → форма с теми же условиями → оставить
   moyareklama.by → «Сохранить» → в «Мои поиски» два поиска, у копии видно «moyareklama.by».
6. **Состояние** (US6): внизу «Мои поиски» — «Все сайты работают · проверены за последние N мин» (или какой сайт
   не работает); у приглашённого — то же.
