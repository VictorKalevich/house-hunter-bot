# Контракт: изменения API и экранов мини-приложения (фича 003)

Базовые контракты — [001](../../001-house-listing-alerts/contracts/miniapp-api.md) и
[002](../../002-search-ux-improvements/contracts/miniapp-api.md): авторизация, ошибки, объекты и методы остаются.
Здесь — только то, что добавляется или меняется. Модель — [data-model.md](../data-model.md), решения —
[research.md](../research.md) R11, R12.

## Объекты

```jsonc
// ListingCard — добавлены id, mark, siteStatus; у distance — from
{
  "id": 48213,                             // новое: listings.id — для отметок
  "mark": "like",                          // новое: "like" | "hide" | null — отметка этого пользователя
  "siteStatus": { "kind": "gone", "at": "2026-11-24T00:41:00Z" },
  //   новое: null | { "kind": "gone", "at": ISO } — проверка увидела, что снято
  //              | { "kind": "unchecked", "lastSeenAt": ISO } — лайк, 7 дней не было в выдаче и проверка не подтвердила
  "source": "realt", "url": "https://realt.by/…", "photoUrl": null, "kind": "house", "isNew": false,
  "priceUsd": 52000, "priceByn": 155000, "houseM2": 90, "plotSotki": 12,
  "distance": { "km": 25.4, "mode": "straight", "approx": false, "fallback": false, "pending": false,
                "from": "Минск" },         // новое: from — только на экранах отметок, иначе нет поля
  "place": "д. Боровляны, Минский р-н",
  "publishedAt": "2026-11-22T09:41:00Z", "createdAt": null
}
```

## Методы

| Метод и путь | Вход | Ответ | Требования |
|---|---|---|---|
| `GET /api/searches/{id}/listings?page=n` | — | Как в 002, но скрытые пользователем объявления не входят ни в `items`, ни в `total`; у карточек — `id`, `mark`, `siteStatus` | FR-009, SC-006 |
| `GET /api/marks?kind=<like\|hide>&page=<n>` | `kind` обязателен; `n` ≥ 1 | `{ "items": [ListingCard], "page": 1, "pageSize": 5, "total": 7 }` — свои отметки этого вида, последние сверху | FR-003, FR-011, US1-4 |
| `PUT /api/listings/{id}/mark` | `{ "mark": "like" \| "hide" \| null }` | `200 { "id": 48213, "mark": "like" }` | FR-001, FR-006, FR-008, FR-010 |

Правила `GET /api/marks`:

- Только отметки пользователя из проверенного `initData` (FR-007). Порядок — `marks.created_at` убыв., по 5.
- `distance` — по прямой от пункта самого нового поиска пользователя, у которого пункт задан; `from` — название
  пункта. Нет такого поиска или координат у объявления → `null`.
- Объявления показываются независимо от 30 дней и условий поисков: это список отметок, а не выдача.
- Ошибки — `422` с `fields.kind` или `fields.page`.

Правила `PUT /api/listings/{id}/mark`:

| Вход | Что происходит |
|---|---|
| `like` | Ставит лайк; скрытие снимается |
| `hide` | Скрывает; лайк снимается |
| `null` | Снимает любую отметку |

- Ответ — итоговая отметка. Повтор того же запроса даёт тот же результат.
- Ошибки:

  | Код | `code` | Сообщение |
  |---|---|---|
  | `404` | `not_found` | «Объявление уже удалено из бота» |
  | `409` | `like_limit` | «В понравившихся уже 100 объявлений — уберите лишние» |
  | `422` | `invalid` | `fields.mark` |

## Экраны

| Экран | Адрес (hash) | Что меняется | Компоненты |
|---|---|---|---|
| Мои поиски | `#/` | Под «Новый поиск» — кнопка «♥ Понравившиеся» → `#/liked` | `ds-btn--block`, `ds-btn--secondary` |
| Объявления поиска | `#/search/{id}/listings?page=n` | Кнопки карточки (ниже). После «Не интересно» карточка сменяется строкой «Скрыто» с кнопкой «Вернуть»; после обновления списка её нет | как в 002 + `ds-row`, `ds-card` |
| Понравившиеся | `#/liked?page=n` | Новый. Заголовок «Понравившиеся»; карточки с кнопками; пейджер; ссылка «Скрытые» → `#/hidden`. Пусто → `ds-empty` | `ds-title`, `ds-listing`, `ds-pager`, `ds-empty`, `ds-btn--sm` |
| Скрытые | `#/hidden?page=n` | Новый. Заголовок «Скрытые»; карточки с кнопками «♡ Нравится» и «Вернуть»; пейджер. Пусто → `ds-empty` | то же |

### Кнопки карточки

Строка `ds-row ds-row--wrap` под местом, по порядку:

| Отметка | Кнопки |
|---|---|
| нет | «♡ Нравится» (`ds-btn ds-btn--sm ds-btn--secondary`, `aria-pressed="false"`), «Не интересно» (`--secondary`), «Открыть объявление» (`--secondary`) |
| лайк | «♥ В понравившихся» (`ds-btn ds-btn--sm`, `aria-pressed="true"`), «Не интересно», «Открыть объявление» |
| скрыто (экран «Скрытые») | «♡ Нравится», «Вернуть», «Открыть объявление» |

Поведение кнопок:

- **Нажатие** — `PUT /api/listings/{id}/mark`. Кнопка недоступна до ответа (SC-001: ≤ 2 с) и перерисовывается по
  отметке из ответа.
- **Ошибка** — `ds-toast` с сообщением API; кнопки — как до нажатия.
- **Снятие лайка на «Понравившихся»** не убирает карточку до обновления экрана: можно передумать.
- **Скрытие в «Понравившихся»** — карточка сменяется строкой «Скрыто» и «Вернуть», как в списке поиска.

### Пометки

| `siteStatus` | Где | Текст |
|---|---|---|
| `gone` | Метка `ds-chip ds-chip--warning` в ряду меток | «Снято с сайта 24.11» (день и месяц по Минску) |
| `unchecked` | Строка `ds-hint` под местом | «Не удалось проверить; в выдаче сайта последний раз 12.11» |

### Расстояние на экранах отметок

Подпись факта — «<from>, по прямой», значение — «25,4 км».

### Тексты

| Где | Текст |
|---|---|
| Пусто, «Понравившиеся» | «Понравившихся пока нет» / «Отмечайте дома кнопкой ♡ Нравится — в уведомлениях и в списках поисков.» |
| Пусто, «Скрытые» | «Скрытых нет» / «Кнопка «Не интересно» убирает дом из списков и уведомлений — здесь его можно вернуть.» |
| Всплывающая строка | «Добавлено в понравившиеся», «Убрано из понравившихся», «Скрыто — больше не покажу», «Возвращено» |

### Переходы

- «Назад» Telegram:
  - «Понравившиеся» → «Мои поиски»;
  - «Скрытые» → «Понравившиеся».
- Кнопка меню бота «Понравившиеся» открывает `/app#/liked` (contracts/telegram-bot.md 003).
