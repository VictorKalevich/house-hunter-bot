## 1. Быстрые тесты

```powershell
npm test
npm run bench
```

Ожидание: всё зелёное, в том числе:

| Что | Ожидание |
|---|---|
| Изменение цены (`priceChange`) | 52 000 $ → 48 000 $ при валюте `USD` — изменение −4 000 $; цена в `USD`, сдвинулись только рубли — нет; −0,5 % — нет; валюта неизвестна, обе цены −5 % — изменение в $; доллары −5 %, рубли +1 % — нет; цена появилась или пропала — нет; продавец сменил валюту — по долларам и рублям |
| Адаптеры, выдача | У каждого объявления сохранённых страниц `priceCurrency` по таблице contracts/source-adapter.md 003; kufar `EUR` → `null` |
| Адаптеры, страницы | realt: живое — цена, `USD`/`BYN`, площади; `archive: 1` — `gone`; moyareklama: цена в BYN и площади; чужая страница — `null` |
| Текст сообщения о цене | «Цена изменилась: было <b>52 000 $</b>, стало <b>48 000 $</b> (−4 000 $)», вторая строка без `<b>`, последняя — «realt.by · в понравившихся» |
| Клавиатуры | Без отметки / лайк / скрыто — по contracts/telegram-bot.md 003; `callback_data` ≤ 64 байт |

| Обезличенность | Новые сохранённые страницы без имён, телефонов и e-mail (`tests/unit/security.test.mjs`) |

| `bench` | `parseCard` realt ≤ 2, moyareklama ≤ 1 единицы CPU |

## 3. Мини-приложение вручную

Новых компонентов дизайн-системы нет — витрина `design-system/preview.html` не меняется. Экраны проверяются в Telegram
после выката (шаг 5).

## 4. Выкат

Порядок — сначала поправка конституции и миграция, потом код:

```powershell
npm test; npm run test:e2e                                   # зелёные на ветке, затем слияние в main
npx wrangler d1 migrations apply house-hunter --remote       # 0004_marks.sql
npx wrangler deploy
node scripts/setup-telegram.mjs                               # меню команд и кнопка меню — без изменений; повторить не вредно
```

Код 002 с применённой 0004 работает: новые колонки и таблицы ему не мешают. Поэтому миграцию можно применить заранее.

## 5. Проверка в Telegram после выката

1. **Лайк под сообщением** (US1). Дождаться уведомления → «♡ Нравится».
   - Ожидание: строка «Добавлено в понравившиеся», кнопка «♥ В понравившихся».
   - Затем `/start` → «Понравившиеся»: дом там.
   - Ещё раз «♥ В понравившихся» — дом пропал из списка после обновления экрана.
2. **Лайк в мини-приложении** (US1-3). «Мои поиски» → поиск → «Показать объявления» → «♡ Нравится» на карточке.
   - Ожидание: кнопка «♥ В понравившихся»; «♥ Понравившиеся» на главном экране — дом там.
3. **Не интересно** (US2). На карточке в списке поиска → строка «Скрыто» и «Вернуть».
   - Назад к итогу: «Сейчас подходят» на 1 меньше.
   - «Понравившиеся» → «Скрытые» → «Вернуть».
4. **Приватность** (US1-6). Второй аккаунт открывает «Понравившиеся» — пусто.
5. **Проверка страниц** (US3, R6, R7) — через сутки после первых лайков.
   - `npx wrangler tail --format json`: работа `card` в отчёте тика, `result: ok | gone | error | blocked`.
   - Если на realt встретится снятое объявление, сверить его ответ: 404 или `archive: 1`. Иначе — разбор по процессу
     bugfix.
   - Проверить, что старое снятое объявление moyareklama отвечает статусом 404.
6. **Цена** (US4) — по мере изменений на сайтах.
   - Сообщение «Цена изменилась…» приходит только по понравившимся.
   - `SELECT status, COUNT(*) FROM price_alerts GROUP BY status` — нет зависших `sending`.
7. **Лимиты** (SC-007): `npx wrangler d1 info house-hunter` — `rows_written_24h` в пределах оценки data-model.md 003;
   в `wrangler tail` нет `exceededCpu`.
